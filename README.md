# Politique de Confidentialite - Move

Ce projet est un site React (Vite) qui affiche la page de politique de confidentialite de l'application Move.

## Contenu de la page

La page presente:

- Un titre: Politique de Confidentialite - Move
- Une date de mise a jour: 16 mars 2026
- Une section Collecte des donnees
- Une section Utilisation
- Une section Conservation
- Un contact: justin.soulard11@gmail.com

## Stack technique

- React
- Vite
- Deploiement GitHub Pages via gh-pages

## Commandes utiles

- Installer les dependances:

```bash
npm install
```

- Lancer le projet en local:

```bash
npm run dev
```

- Generer la version de production:

```bash
npm run build
```

- Previsualiser le build:

```bash
npm run preview
```

- Deployer sur GitHub Pages:

```bash
npm run deploy
```

## Configuration GitHub Pages

Le projet utilise deja la base suivante dans la config Vite:

```js
base: "/MoveContact/WebSite/";
```

Assure-toi que le depot GitHub et la configuration Pages correspondent a ce chemin.
